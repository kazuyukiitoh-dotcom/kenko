# 体重・血圧ノート

体重と血圧を記録してグラフで確認できるWebアプリ(PWA)です。
サーバーもアカウントも不要で、データは端末のブラウザ内にのみ保存されます。

## 機能

- 体重・血圧(収縮期/拡張期)・脈拍・メモの記録
- 血圧と脈拍は2回測定して**平均値で記録**(2回目未入力なら1回目の値をそのまま採用)。入力中に平均をその場で表示
- 体重・血圧(平均)・脈拍(平均)の推移グラフ(7日/30日/90日/全期間、家庭血圧の基準線 135/85 付き)
- 選択した期間の平均値(体重・血圧・脈拍)を表示
- 記録の一覧・編集・削除
- CSV書き出し(Excel対応)/ JSONバックアップ・復元
- オフライン動作(HTTPSで配信した場合)
- ダークモード対応

## パソコンで使う

`index.html` をブラウザで開くだけで使えます。

## iPhoneで使う

iPhoneのSafariからこのアプリを開くには、HTTPSのURLで公開するのが確実です。
おすすめは **GitHub Pages(無料)** です。

1. GitHubにリポジトリを作り、このフォルダのファイル一式をアップロードする
2. リポジトリの Settings → Pages → Branch を `main` にして保存
3. 発行されたURL(`https://ユーザー名.github.io/リポジトリ名/`)をiPhoneのSafariで開く
4. 共有ボタン → **「ホーム画面に追加」**

これでホーム画面から普通のアプリのように起動でき、オフラインでも動きます。

> 同じWi-Fi内でPCから一時的に試すだけなら、このフォルダで
> `python -m http.server 8000` を実行し、iPhoneから `http://PCのIPアドレス:8000` を開く方法もあります
> (この方法ではオフライン機能は使えません)。

### データの引き継ぎ(PC ⇔ iPhone)

データは端末ごとに保存されるため、移行するときは
「データ」タブ → **JSONで書き出す** → ファイルをAirDropやメール等で送る → 移行先で **JSONを読み込む** としてください。

### ヘルスケアアプリ(Apple Health)との連携について

WebアプリからはヘルスケアAPIに直接アクセスできません(Appleの仕様上、ネイティブアプリのみ)。
代わりに次の方法があります。

- **ショートカットを使う**: iPhoneの「ショートカット」アプリには「ヘルスケアサンプルを記録」アクションがあります。
  「体重と血圧を聞いてヘルスケアに記録し、ついでにこのアプリのURLを開く」といったショートカットを組めば、
  ほぼワンタップで両方に記録できます。
- 記録はこのアプリを主にして、ヘルスケアには必要なときだけ手動で転記する運用もシンプルです。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面(記録・グラフ・履歴・データの4タブ) |
| `style.css` | スタイル(ライト/ダーク対応) |
| `app.js` | 記録の保存・一覧・書き出しなどのロジック |
| `chart.js` | SVG折れ線グラフ描画(依存ライブラリなし) |
| `manifest.webmanifest` | PWA設定(ホーム画面追加用) |
| `sw.js` | Service Worker(オフラインキャッシュ) |
| `icons/` | アプリアイコン |

## データ形式

localStorage のキー `health-records-v1` に以下の配列がJSONで保存されます。

```json
{
  "id": "一意ID",
  "date": "2026-07-04",
  "time": "07:30",
  "weight": 65.2,
  "sys1": 130, "dia1": 85, "pulse1": 68,
  "sys2": 126, "dia2": 83, "pulse2": 66,
  "sys": 128, "dia": 84, "pulse": 67,
  "note": "起床後"
}
```

`sys` / `dia` / `pulse` は2回測定の平均(四捨五入)。グラフ・統計はこの平均値を使います。
2回目を入力しなかった場合は `sys2` などが `null` になり、平均=1回目の値です。
